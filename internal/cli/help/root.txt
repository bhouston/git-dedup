git-dedup <command> [options]

Git commands pass through to Git; clone, submodule, and worktree can use the
shared store.

Commands:
  git-dedup docgen  Write the OpenCLI document to a file, or stdout if --output
                    is omitted
  git-dedup store   store commands

Options:
  --version  Show version number                                       [boolean]
  --help     Show help                                                 [boolean]
  --stats    Show object pool use and checkout adoption measurements   [boolean]
