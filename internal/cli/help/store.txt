git-dedup store

store commands

Commands:
  git-dedup store                Show the shared store and its health  [default]
  git-dedup store add [path]     Add a local checkout to the shared store;
                                 linked checkouts depend on it
  git-dedup store fetch          Fetch registered remotes into the shared object
                                 pool
  git-dedup store gc             Compact the shared object pool without pruning
                                 consumer objects
  git-dedup store list           List remotes registered in the shared store
  git-dedup store prune          Reclaim pool objects that no registered
                                 checkout uses
  git-dedup store remove <path>  Detach a checkout and its submodules from the
                                 shared store

Options:
  --version  Show version number                                       [boolean]
  --help     Show help                                                 [boolean]
  --stats    Show object pool use and checkout adoption measurements   [boolean]
