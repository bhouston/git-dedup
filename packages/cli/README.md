# gitx CLI

`gitx` forwards ordinary Git commands and adds a shared object store for supported clones, submodules, and worktrees. Run `gitx --help` for store commands. Run `gitx docgen` or `gitx __opencli` to generate an OpenCLI document.

The package installs the `gitx` executable. Use `gitx clone`, `gitx cache`, or any ordinary Git command through `gitx` when you want shared storage behavior.
